# Chrome 扩展

[English](chrome-extension.md) | **简体中文**

Keyward 扩展读取本地服务中的加密保险库，在选择账号后填充登录信息。需要 Chrome 106 或更高版本，以及本地 Keyward Node 服务。目前尚未在 Chrome 网上应用店发布。

## 安装

在仓库根目录构建扩展：

```bash
npm run build:extension
```

在 Chrome 打开 `chrome://extensions`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择生成的 `dist/chrome` 目录。Edge 对应的页面为 `edge://extensions`。

启动本地服务：

```bash
npm start
```

打开 http://127.0.0.1:8787 创建保险库或管理条目。使用扩展时需保持服务运行。如果通过 `PORT` 更改了服务端口，请在弹窗的“本地连接”中填写相同端口。扩展仅支持 `127.0.0.1`，不能连接远程 Keyward 服务。

## 填充登录信息

1. 在网页版保险库中设置登录条目的网址，例如 `https://example.com`。
2. 打开该网站的登录页面，点击 Keyward 扩展图标。
3. 输入主密码，在目标账号旁点击“填充”。
4. 检查填充内容后自行提交，扩展不会调用表单提交操作。

匹配依据为精确的网站来源，包括协议、主机名和端口。条目中的 `example.com` 表示 `https://example.com`，不匹配 `login.example.com`、`example.com.evil.test` 或其他端口。弹窗显示规范化来源，国际化域名显示为 punycode 编码。公共 HTTP 网站不受支持，HTTP 回环地址可用于本地开发。

首版仅填充主框架。页面必须有唯一、可见且可编辑的登录密码框，标记为 `autocomplete=new-password` 的字段不参与填充。表单提交目标如果属于其他来源，会被拒绝。存在多个候选密码框或用户名框时，扩展可能拒绝填充，不会猜测。暂不支持 iframe 登录、注册表单或仅输入用户名的分步页面；自定义控件可能需要手动输入。

## 解锁与复制

扩展弹窗独立于网页版解锁。关闭弹窗、点击“锁定”或闲置五分钟后，会清除会话状态，再次打开需要重新输入主密码。锁定会取消读取请求，读取请求也设有五分钟上限。不使用后台解锁会话，不持久化明文密码。

生成器复用现有 Keyward 实现，支持 8 到 128 位密码。“复制”会将生成的密码写入系统剪贴板。网页版会尝试延时清除，扩展中的复制内容则**不会自动清除**。

数据处理和权限说明见[隐私政策](../PRIVACY.zh-CN.md)。

## 打包与商店发布

```bash
npm run check
npm test
npm run pack:extension
```

打包命令重新构建扩展并生成 `dist/keyward-chrome-0.1.0.zip`，`manifest.json` 位于压缩包根目录。包内包含共用的核心代码、中英文界面、图标和 MIT 许可证，不包含 Node 服务端、保险库文件或密钥。GitHub Actions 已配置构建 ZIP，并上传为 `keyward-chrome` 构建产物。

完成浏览器验证后，可使用 ZIP 提交 Chrome 网上应用店审核。发布还需要开发者账号、截图、明确说明本地服务要求的商店介绍、可访问的隐私政策链接、准确的数据使用披露和权限理由。当前包为开发版本，尚未完成商店审核或发布。

## 验证

自动化测试覆盖匹配、解密、锁定、请求取消、重定向、标签页与文档变更、表单选择、受控输入框事件、弹窗流程、语言资源和打包。模拟 DOM/API 测试不能替代真实 Chrome 或 Edge 安装验证。

商店提交前，需验证安装、实际弹窗渲染、本地服务连接、正确与错误主密码、测试网站填充、锁定及关闭后重新打开、剪贴板行为，以及对不支持表单的拒绝。验证使用合成的测试账号。设计决定与回滚对象见[扩展设计](design/chrome-extension.md)。
